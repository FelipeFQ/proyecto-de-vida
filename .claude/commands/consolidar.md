Revisa la conversación completa de esta sesión e identifica todo lo que debería quedar documentado en el sistema Proyecto de Vida.

**Proceso:**

1. Recorre la conversación desde el inicio buscando: cambios de estado, decisiones tomadas, información nueva, aprendizajes, correcciones a lo que había documentado.

2. Para cada elemento encontrado, verifica el contenido actual del archivo destino — solo proponer si el cambio no está ya reflejado.

3. Presenta cada propuesta con el formato exacto de abajo, lista para aprobar o rechazar.

---

**Tipos de información a buscar:**
- Cambios de estado: tarea completada, nuevo/ex cliente, nueva lesión o recuperación, dato financiero actualizado
- Decisiones tomadas: precio, estrategia, timing, estructura del programa
- Aprendizajes sobre el sistema: señales de entrada de clientes, patrones, qué funcionó o no
- Cambios en prioridades o planes
- Información nueva que no existía antes en el sistema

**Regla de prioridad de archivos:**
- Si es estado actual de cualquier área → `vida/estado_actual.md`
- Si es operación de coaching → `cimientos/` (archivo específico)
- Si es financiero o inmobiliario → `finanzas/` (archivo específico)
- Si es deportivo o de lesión → `ultimate/` (archivo específico)
- Si es un aprendizaje estructural del sistema → `_perfil/manual_operativo.md`
- Si es identidad o visión → `_perfil/perfil_felipe.md` (solo si es trascendental)
